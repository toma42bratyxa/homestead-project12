# PHP Backend Development Environment (Homestead & Vagrant)

Проект представляет собой настроенную среду разработки на базе виртуальной машины Homestead/Vagrant, соответствующую всем требованиям задания на максимальный балл (20 баллов).

## 📋 Характеристики стенда и конфигурация

* **Имя виртуальной машины**: PHP Backend
* **IP-адрес**: `192.168.10.42`
* **Доменное имя**: `application.local`
* **Проброс портов**:
  * SSH: хостовый порт `2242` -> гостевой `22`
  * HTTPS: хостовый порт `4430` -> гостевой `443`
  * HTTP: хостовый порт `8080` -> гостевой `80`
* **Синхронизация папок**: 
  * Код проекта проброшен из хостовой директории `D:/laragon/www/homestead-project` в `/home/vagrant/code` на виртуалке.
  * Точка входа веб-сервера настроена на папку `public/`.

---

## 🚀 Реализованные критерии оценки

1. **Базовая часть (10 баллов):**
   * Развернута виртуальная машина с помощью конфигурационного файла `Homestead.yaml`.
   * Присвоен требуемый IP-адрес (`192.168.10.42`) и имя (`PHP Backend`).
   * Настроен проброс директорий и SSH-порт (`2242`).
   * Сайт доступен по доменному имени `application.local` и выводит приветственное сообщение.

2. **Расширенная часть (15 баллов):**
   * Дополнительно настроен проброс безопасного HTTPS-порта (`443` -> `4430`).

3. **Максимальная часть (20 баллов):**
   * В конфигурации веб-сервера Nginx (`nginx.conf`) настроено кэширование статических файлов (`expires`, `add_header Cache-Control`) для оптимизации отдачи картинок, стилей CSS и скриптов JS.

---

## 🛠 Состав проекта

* `Homestead.yaml` — файл конфигурации виртуальной машины.
* `Vagrantfile` — конфигурация сборки Vagrant.
* `nginx.conf` — файл настроек веб-сервера Nginx с правилами кэширования статики.
* `public/index.php` — точка входа приложения с приветствием.
